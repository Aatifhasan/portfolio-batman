## 🛠️ Features

- 🦇 **Batman & Bruce Wayne Dual Persona**: Interactive dark-themed aesthetic showcasing technical mastery and project portfolio.
- ⚡ **Split-Face Hero Section**: Custom-designed split visual artwork with interactive hover & perspective movement.
- ✉️ **Web3Forms Integration**: Fully functional, serverless contact form delivering transmissions directly to email inbox with real-time feedback.
- 📜 **Gotham Scroll & Animations**: Micro-interactions, animated spotlight beams, floating ember particles, and smooth section reveals.
- 📱 **Fully Responsive**: Optimized for ultra-fast performance across mobile, tablet, and desktop viewports.

---

## 🚀 Tech Stack

- **Frontend**: React 18, JavaScript (ES6+), HTML5, Vanilla CSS3
- **Animations**: `react-type-animation`, CSS Keyframes, Perspective 3D Transforms
- **Contact Form**: Web3Forms API
- **Deployment**: Vercel & GitHub

## 💻 Local Development

### 1. Clone the repository
```bash
git clone https://github.com/Aatifhasan/portfolio-batman.git
cd portfolio-batman
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm start
```
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

### 4. Build for production
```bash
npm run build
```
